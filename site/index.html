功能一览

调试链路，一次配齐

从发出请求到校验结果，中间需要的东西都做进去了。

HTTP 全方法调试

GET / POST / PUT / DELETE / PATCH，参数、请求头、表单、raw、Bearer 与 Basic 认证一应俱全，支持自定义超时。

响应结构化查看

JSON 树逐层折叠与语法高亮，原始文本、图片与 HTML 页内预览，响应头与请求头对照。

项目分组管理

多个项目、多级文件夹整理接口，拖拽排序与跨层移动，随时保存、复制、重命名。

环境与变量

开发 / 测试 / 生产多环境一键切换，{{变量}} 在发送前自动替换，URL 输入框实时预览解析结果。

断言测试

状态码、耗时、JSON 路径、响应头、响应体五类断言，发送后自动校验，失败原因逐条列出。

变量自动提取

从响应中按 JSON 路径提取 token、id 等字段，自动写入当前环境，串联登录与业务接口。

代码生成

按当前请求的实际参数，一键导出 cURL、Fetch、Axios、Python 与 Go 代码，直接粘进工程。

多格式导入

支持 cURL、Postman Collection、固定 JSON 格式与抓包记录导入，批量建接口、自动建文件夹。

页面抓包

开启捕获后，浏览网页时产生的接口请求自动记录，选中任一条即可导入为可调试的接口。

WebSocket 调试

建立长连接、按时间线收发消息，连接状态呼吸灯实时反馈，与 HTTP 接口在同一处管理。

Cookie 管理器

按域名查看、编辑、清空站点 Cookie，一键复制 Cookie 请求头，调试登录态更顺手。

数据只存本地

项目、环境与历史记录全部保存在浏览器本地存储，不经过任何服务器，导出备份一键带走。

开始使用

三步装好，打开即用

未上架应用商店，以开发者模式加载，全程不到一分钟。

01

下载并解压

下载插件包 penapi-1.0.0.zip，解压到任意固定目录。请勿删除该目录，扩展会随目录失效。

02

打开扩展管理页

地址栏访问 chrome://extensions（Edge 为 edge://extensions），打开右上角的「开发者模式」。

03

加载扩展

点击「加载已解压的扩展程序」，选择解压后的文件夹。完成后点击工具栏的 PenApi 图标，进入全屏调试页。

插件更新时，把新版本解压覆盖原目录，在扩展管理页点击刷新即可，本地数据不会丢失。若提示需要额外权限，请在扩展卡片上确认。
