v1.0.0 全新发布 2026-11-18

接口调试

  • HTTP 全方法请求：GET / POST / PUT / DELETE / PATCH，参数、请求头、表单、raw 请求体，Bearer 与 Basic 认证，自定义超时
  • 响应查看：JSON 树逐层折叠与高亮、原始文本、图片与 HTML 页内预览，响应头与请求头对照
  • WebSocket 调试：长连接收发消息时间线，连接状态呼吸灯

项目与环境

  • 项目分组：多项目、多级文件夹管理接口与 WS，拖拽排序，历史记录按日期分组
  • 环境变量：多环境一键切换，{{变量}} 发送前自动替换，URL 实时预览解析结果

测试与代码

  • 断言测试：状态码、耗时、JSON 路径、响应头、响应体五类断言，失败原因逐条列出
  • 变量提取：JSON 路径提取响应字段自动写入环境变量，串联登录与业务接口
  • 代码生成：按当前请求一键导出 cURL / Fetch / Axios / Python / Go

导入与工具

  • 多格式导入：cURL、Postman Collection、固定 JSON 格式、页面抓包记录
  • 页面抓包：捕获浏览器中产生的接口请求，选中即导入为可调试接口
  • Cookie 管理器：按域名查看、编辑、清空 Cookie，一键复制 Cookie 请求头
  • 本地存储：全部数据只存浏览器本地，支持备份导出与导入
